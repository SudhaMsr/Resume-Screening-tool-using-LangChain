# Data Scientist, Applied ML

We're a health-tech company building ML features that clinicians use every day. You'll take models from idea to production and explain them to non-technical stakeholders.

## What you'll need
- 2+ years building machine learning models in Python
- Strong SQL and pandas for analysis and feature engineering
- Experience with scikit-learn and XGBoost or similar
- Deep learning with PyTorch or TensorFlow
- Solid statistics: hypothesis testing, A/B tests, regression
- Clear communication with stakeholders

## Nice to have
- LLMs and RAG, ideally with LangChain
- NLP on clinical or free-text data
- Cloud (AWS or GCP) and Docker
- MLOps: MLflow, model monitoring, CI/CD
